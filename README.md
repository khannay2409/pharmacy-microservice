# 💊 Real-Time Pharmacy System

A **Spring Boot microservices** project simulating a real-time pharmacy workflow — from order creation to payment and inventory update — using **Apache Kafka**, **Spring Cloud Config**, and **MySQL**.

### 🧩 Key Highlights
- Event-driven communication via **Kafka**
- Centralized config using **Spring Cloud Config Server**
- **Structured JSON logging** with `traceId` for cross-service tracing
- **Independent services:** Order, Payment, Inventory
- **Resilient & scalable** with Spring Retry and WebFlux

### 🛠️ Tech Stack
Java 17 · Spring Boot 3 · Kafka · MySQL · Docker · Logstash · Spring Cloud
